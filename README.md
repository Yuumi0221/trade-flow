# TradeFlow - 交易指令处理工具

一个基于Web的批量交易指令处理工具，支持自然语言输入，自动计算各产品应买卖的股数。

## 功能特点

- 📝 **自然语言指令解析** - 支持"所有产品买一个点"等自然语言格式
- 📊 **实时行情数据** - 东方财富实时股票价格
- 🔢 **自动股数计算** - 根据点数和产品净资产自动计算
- 📋 **成交反馈统计** - 验证实际配置比例
- 💾 **本地数据存储** - 无需服务器，数据本地保存

## 快速开始

### 打开应用

在浏览器中打开 `index.html` 文件即可使用。

### 输入指令

```
所有产品买一个点寒武纪
所有产品卖两个点宁德时代
```

**支持的语法**：
- 操作方向：`买`、`卖`、`买入`、`卖出`、`加仓`、`减仓`
- 点数：`一个点`、`两个点`、`半个点`、`1个点`、`2%`
- 产品范围：`所有产品`、`所有基金`、`全部`

### 查看结果

- 🔴 **红色背景** = 买指令
- 🔵 **蓝色背景** = 卖指令

表格显示：平台、证券代码、证券名称、现价、百分比、各产品应买卖股数

### 成交反馈

1. 输入各产品的成交价
2. 输入各产品的市值（市值以万为单位，如输入150表示150万）
3. 点击"计算反馈"
4. 点击"复制结果"一键复制

## 股数计算公式

```
应买卖股数 = ROUND(点数 × 产品净资产 × 0.01 / 现价 / 100) × 100

百分比 = (股数 × 现价) / 产品净资产 × 100%
```

说明：股数四舍五入到百位

## 产品管理

| 功能 | 说明 |
|------|------|
| 添加产品 | 输入产品名称和净资产 |
| 编辑产品 | 直接修改现有产品信息 |
| 删除产品 | 移除不需要的产品 |
| 导出配置 | 导出为JSON文件备份 |
| 导入配置 | 从JSON文件恢复 |

## 部署

### 本地运行

```bash
# Python 3
python -m http.server 8000

# 然后访问 http://localhost:8000
```

### 环境要求

- 现代浏览器（Chrome/Firefox/Edge）
- JavaScript已启用
- 支持localStorage

## 数据格式

**产品结构**：
```json
{
  "id": "xxx",
  "name": "产品名称",
  "netAssets": 10000000
}
```

## 注意事项

- 数据存储在浏览器本地（localStorage）
- 更换浏览器需重新配置或导入已导出的配置
- 价格为东方财富实时数据，可能存在延迟

## 常见问题

**Q: 支持多少个产品？**
A: 理论上无限制，取决于浏览器性能。

**Q: 数据会上传吗？**
A: 不会，所有数据存储在本地。

**Q: 市值输入格式？**
A: 输入万位及以上数字，如150表示150万。
